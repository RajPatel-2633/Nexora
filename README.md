# 📖 Overview

Nexora CRM is a premium marketing website for a **360° CRM platform** that helps businesses manage their complete sales and operations workflow from a single workspace.

The website focuses heavily on:

- Premium UI Design
- Production-grade animations
- Responsive layouts
- Modern SaaS aesthetics
- Smooth user experience
- Scalable architecture for future backend integration

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/RajPatel-2633/nexora.git
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build production version

```bash
npm run build
```
